# Roadmap

## Phase 1 — Foundations

- [ ] Create repo structure.
- [ ] Add core docs:
  - README
  - manifesto
  - architecture
  - policy model
  - economic models
- [ ] Implement minimal economic engine:
  - base formula,
  - simple inputs,
  - basic outputs.

## Phase 2 — Scenarios and UI

- [ ] Add scenario definitions (`scenarios.py`).
- [ ] Implement CLI interface.
- [ ] Build simple web frontend:
  - input fields,
  - charts,
  - scenario comparison.

## Phase 3 — Agent Integration

- [ ] Expose simulator via API (`/api/server.py`).
- [ ] Integrate with personal OS (e.g., AblesLab):
  - agents that:
    - explain scenarios,
    - help users plan,
    - allocate resources.

## Phase 4 — Policy Engagement

- [ ] Publish a short explainer based on the simulator.
- [ ] Share with:
  - researchers,
  - policy thinkers,
  - civic technologists.
- [ ] Iterate based on feedback.

## Phase 5 — Expansion

- [ ] Add more complex economic models.
- [ ] Model:
  - displacement,
  - inequality,
  - infrastructure access.
- [ ] Explore:
  - regional variants,
  - global models,
  - cooperative implementations.

The roadmap is intentionally flexible.  
The goal is to **keep moving**, not to lock in a rigid plan.
